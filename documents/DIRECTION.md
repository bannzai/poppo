# 方向性: Poppo

## 仮説

外国語のチャット (Slack・Discord など) を iPhone で読み書きする人は、翻訳アプリとチャットアプリの間でコピーと貼り付けを往復している。本体アプリが画面を読み取って翻訳と返信案を作り、キーボードを開くだけでそれが出てくれば、アプリを切り替えずに読んで返信できる。

評価の全文は [evaluation/2026-11-17-report.md](evaluation/2026-11-17-report.md) (評価した時点の記録で、以後の更新はこの文書に書く)。

## 判定基準

| 指標 | 計測元 (skill / コマンド) | 継続のしきい値 | 打ち切り条件 | 転換の条件 |

| 実機で、背面の一連の処理 (取り込み → 読み取り → 翻訳 → 返信案 → キーボードに表示) が回った回数 (公開前) | 開発者メニューの診断の記録を実機で見る (ユーザー作業の一覧 issue の「実機・実環境での確認」) | 10 回試して 8 回以上 | 10 回試して 0 回で、本体アプリを前面に戻した時だけ処理する形でも成り立たない | 背面では回らないが前面に戻すと回るなら、キーボードを開く前に本体アプリへ戻る形に変える |
| 公開後 14 日のダウンロード数 | App Store Connect の Sales and Trends (取得するコマンドは公開の前に決めてこの行に書く) | 100 以上 | 2 回連続 30 未満 | 製品ページの表示回数は多いがダウンロードが少なければ、製品ページの訴求を変える |
| 取り込みを 1 回以上始めた人のうち、キーボードから返信案を入力した人の割合 | 計測基盤を入れた後に決める (公開前は計測しない) | 30% 以上 | 2 回連続 10% 未満 | 翻訳は読まれるが返信案が使われなければ、返信案を外して翻訳だけにする |

## 必要な機能

- [ ] スクリーンショットからの読み取り (本体アプリ。開くと直近に撮ったスクリーンショットをすぐ選べ、選ぶとその翻訳と返信案が本体アプリの画面に出て、返信案をコピーできる)
- [ ] 取り込みの開始と停止 (本体アプリ。画面全体を選ぶ、取り込み中であることの表示、始める前の同意の画面)
- [ ] 画面の文字の読み取りと、チャットの発言の抜き出し
- [ ] 発言の翻訳 (端末内。言語のダウンロードを本体アプリの画面で済ませる)
- [ ] 返信案の生成 (端末内のモデル。使えない端末では翻訳だけを出す)
- [ ] キーボード: 直前の読み取り結果 (翻訳と返信案) を表示し、返信案をタップで入力する。次のキーボードへ切り替えるキーを持つ
- [ ] 初回の案内 (キーボードの追加の手順、取り込みの説明)
- [ ] 設定 (自分の言語、読み取り結果の削除、利用規約とプライバシーポリシーへのリンク、問い合わせ先)
- [ ] 開発者メニュー (DEBUG ビルドだけ。読み取り結果の見本の保存、診断の記録の表示)

## agent に任せること

- 画面の細部 (文言・余白・色・アイコン) と、画面の中の要素の並べ方

## 用語

| 用語 | 定義 | 使わない言い換え |
| --- | --- | --- |
| 本体アプリ | ホーム画面から開く Poppo のアプリ。取り込み・読み取り・翻訳・返信案の生成を行う | メインアプリ・ホストアプリ |
| キーボード | Poppo のカスタムキーボード。他のアプリの入力欄で開き、読み取り結果を表示して返信案を入力する | 拡張・エクステンション |

| 返信案 | 読み取った発言に対して本体アプリが作る返信の文。キーボードではタップするとその文が入力欄に入り、本体アプリではコピーできる | 候補・提案・サジェスト |
