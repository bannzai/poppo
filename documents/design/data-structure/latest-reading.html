POPPO / 新しいデータ構造

読み取り結果

本体アプリが画面を読むたびに保存し、キーボードが読む唯一のデータ。App Group の共有コンテナに 1 つのファイルとして置き、常に最新の 1 つだけを上書きで持つ。

tmux window: 2.1.326 (poppo:0)
セッション再開:
cd /Users/bannzai/ghq/github.com/bannzai/poppo
claude --resume f9d1a877-c94a-4489-ad19-3bf9b3508b47

型定義 (Swift)

/// 読み取り結果。本体アプリが直前に画面から読んだ発言と、その翻訳と、返信案の組。
/// 本体アプリが画面を読むたびに上書きし、キーボードはこれを読んで表示する。
struct LatestReading: Codable {
    /// 画面を読んだ時刻。キーボードが「何分前の内容か」を出すのに使う
    let capturedAt: Date
    /// 画面に見えていた発言。画面の上から下の順
    let messages: [TranslatedMessage]
    /// 返信案。端末内のモデルが使えない端末では空
    let replySuggestions: [ReplySuggestion]
}

/// 画面から読んだ 1 つの発言と、その翻訳
struct TranslatedMessage: Codable {
    /// 画面から読んだままの文 (相手の言語)
    let originalText: String
    /// 利用者の言語に訳した文
    let translatedText: String
}

/// 1 つの返信案
struct ReplySuggestion: Codable {
    /// タップした時に入力欄へ入る文 (相手の言語)
    let text: String
    /// その文の意味を利用者の言語で書いた文。送る前に内容を確かめるために出す
    let meaning: String
}

利用者の操作と、その時に読み書きするデータ

利用者の操作動く側読み書きするデータ
本体アプリで「取り込みを開始」を押し、画面全体を選ぶ 本体アプリ なしまだ何も保存しない
チャットアプリを開いて会話を表示する 本体アプリ (背面) 書くLatestReading の全体を上書きする (capturedAt・messages・replySuggestions)
入力欄をタップし、キーボードを Poppo に切り替える キーボード 読むLatestReading の全体。capturedAt から「何分前の内容か」を出す
相手の発言の翻訳を読む キーボード 読むmessages[].translatedText (原文は originalText)
返信案の意味を確かめてタップする キーボード 読むreplySuggestions[].meaning を表示し、text を入力欄に入れる。保存はしない
チャットの画面が進む (新しい発言が届く・スクロールする) 本体アプリ (背面) 書くLatestReading の全体を新しい内容で上書きする。前の内容は残らない
本体アプリで「取り込みを停止」を押す 本体アプリ 消すLatestReading のファイルを削除する
設定で「読み取り結果を削除」を押す 本体アプリ 消すLatestReading のファイルを削除する

スクリーンショットから読む時 (後から足した機能)

取り込みを始めずに、本体アプリで選んだスクリーンショットから翻訳と返信案を出す使い方。結果は本体アプリの画面に出すだけで、LatestReading には書かない。キーボードには出ない。

利用者の操作動く側読み書きするデータ
本体アプリを開き、直近に撮ったスクリーンショットを選ぶ 本体アプリ なし発言と翻訳 (TranslatedMessage) と返信案 (ReplySuggestion) を作って画面に出す。保存しない
返信案をコピーする 本体アプリ なし返信案の text を端末のクリップボードに入れる。保存しない
結果の画面を閉じる・別のスクリーンショットを選ぶ 本体アプリ なし画面に出していた結果は残らない

持たないもの

  • 過去の読み取り結果。上書きするので、残るのは最新の 1 つだけ
  • 画面の画像。文字を読んだ後は保存しない
  • 発言した人の名前、どのアプリの画面か、会話を区別する番号
  • 利用者がどの返信案を選んだかの記録

依頼の文は「直前の翻訳と返信案がすぐ出てくる」で、履歴や会話ごとの管理は含まれていないため、足していない。

見てほしい点

  • 返信案に meaning (意味を自分の言語で書いた文) を持たせている。相手の言語の文だけでは、送る前に内容を確かめられないため。依頼の文には無い項目なので、要らなければ外す
  • 履歴を持たず、取り込みを止めたら消す。後から履歴が欲しくなった時は、この型とは別の保存先を足す
