型定義 (Swift)

新しく定義するのは ReadingMoment・ScreenImage・RecordingPosition・Chat・ChatSection・CaptureRecording の 6 つ。LatestReading (キーボードに渡す読み取り結果) と ReplySuggestion は今ある型をそのまま使う。LatestReading は名前が「最新」だが、読んだ時刻・発言・返信案という中身が同じなので、同じ項目の型を 2 つ作らずに過去の時点にも使う。TranslatedMessage には項目を 1 つ足す (下)。

/// 読み取った時点。会話の画面の 1 ページになる、画面の画像と、その時に読んだ発言・翻訳・返信案の組。
/// 本体アプリの中 (端末) に置き、読んでから 14 日が過ぎたものは消す。キーボードからは読まない
struct ReadingMoment: Codable, Identifiable {
    /// 読み取った時点ごとに振る識別子。本体アプリの中に置く画面の画像のファイル名にも使う
    let id: UUID
    /// その時に画面から読んだ発言と、その翻訳と、返信案。画面を読んだ時刻 (capturedAt) もこの中にある
    let reading: LatestReading
    /// どのチャットの画面だったか (Chat の id)。画面の上部からチャットの名前を読めなかった時は nil で、
    /// 一覧では「チャットを読み取れなかった画面」の 1 行にまとめる
    let chatID: UUID?
    /// 読み取った時の画面の画像がどこにあるか
    let screenImage: ScreenImage
    /// 取り込みの動画の中の位置。スクリーンショットから読んだ時点は nil。
    /// 指している動画が先に消えた時 (動画は取り込みを始めてから 14 日で消える) も、この値は書き換えない。
    /// 動画が無い時は「この時点の動画を見る」を出さない
    let recordingPosition: RecordingPosition?
    /// 利用者がこの時点に付けたメモ。付けていない時は nil
    var memo: String?
}

/// 読み取った時の画面の画像の置き場所
enum ScreenImage: Codable {
    /// 本体アプリの中に置いたファイル (取り込みで読んだ画面)。ファイル名は ReadingMoment の id から決まる
    case appContainerFile
    /// 写真ライブラリにある元のスクリーンショット (利用者が選んだスクリーンショット)。
    /// 利用者が元の画像を消すと、画像は見られなくなる (発言・翻訳・返信案・メモは残る)
    case photoLibraryAsset(localIdentifier: String)
}

/// 読み取った時点が、取り込みの動画のどこに当たるか
struct RecordingPosition: Codable {
    /// どの取り込みの動画か (CaptureRecording の id)
    let captureRecordingID: UUID
    /// 動画の先頭から何秒の所か
    let secondsFromStart: Double
}

/// チャット。一覧の 1 行で、会話の画面 1 つに当たる
struct Chat: Codable, Identifiable {
    /// チャットごとに振る識別子
    let id: UUID
    /// 一覧と会話の画面に出す名前。最初は画面の上部から読んだ文字で、利用者が書き換えられる
    var title: String
    /// 画面の上部から読んだままの名前。新しく読んだ画面がこのチャットのものかを比べるのに使う
    /// (空白と大文字小文字をそろえて比べる)。利用者が title を書き換えても変えない
    let titleReadFromScreen: String
    /// 一覧のどのセクションに置くか (ChatSection の id)。置いていない時は nil で、一覧の先頭に並べる
    var sectionID: UUID?
}

/// 一覧のセクション。利用者が自由に作って、チャットを分ける (「Slack」「仕事」など)
struct ChatSection: Codable, Identifiable {
    /// セクションごとに振る識別子
    let id: UUID
    /// 利用者が付けた名前
    var name: String
}

/// 取り込み 1 回の動画。取り込みを始めてから終わるまでを 1 本にする。始めてから 14 日が過ぎたものは消す。
/// 終わった時刻は持たない (利用者が止める以外に、エラーや本体アプリの終了でも終わるため。動画の長さはファイルから分かる)
struct CaptureRecording: Codable, Identifiable {
    /// 取り込みごとに振る識別子。動画のファイル名にも使う
    let id: UUID
    /// 取り込みを始めた時刻
    let startedAt: Date
}

今ある型に足す項目 (新しい型ではない)。TranslatedMessage は LatestReading の中に入っているので、キーボードに渡す読み取り結果にも発言した人の名前が入る:

struct TranslatedMessage: Codable {
    let originalText: String
    let translatedText: String
    /// 発言した人の名前。画面から読めなかった時は nil
    let speakerName: String?   // ← 足す。「人物ごとに分かれている感じ」のため
}

置く場所: 本体アプリのコンテナの Application Support/ の下。ReadingMoments/<id>.json と ReadingMoments/<id>.jpg (取り込みで読んだ画面だけ)、Chats/<id>.json、ChatSections/<id>.json、CaptureRecordings/<id>.json と CaptureRecordings/<id>.mp4。キーボードと共有する場所 (App Group) には置かない。

無料の利用者の読み取りの回数 (1 日 10 回まで・通算 100 回まで) の数え方と置き場所は、課金の実装の issue で決める。この型には入れていない。

(操作なし) 取り込みがエラーで止まる・アプリの外で止められるキーボードに渡す読み取り結果は、今と同じく止まった時に消える。動画のファイルが再生できる形で残るかは、実機で確かめるLatestReading を消す。CaptureRecording は変えない

スクリーンショットを選んで読む翻訳と返信案が出る (今と同じ)。読み取った時点を 1 つ足す。無料の利用者でも残るReadingMoment を 1 つ書く (screenImage = photoLibraryAsset、recordingPosition = nil)。画像は写さない。取り込みと同じく、画面の上部の名前で Chat を探して chatID に入れ、初めての名前なら Chat を 1 つ書く
本体アプリを開く一覧が出る。利用者が作ったセクションごとにチャットが並び、行に読み取りの回数と最後に読んだ時が出るChatSection・Chat・ReadingMoment を読む

一覧でセクションを消すセクションが無くなり、中にあったチャットは一覧の先頭 (セクションに置いていないチャット) に戻る。チャットと読み取った時点は消えないその ChatSection を消し、それを指していた Chat の sectionID を nil に書き換える
チャットの名前を書き換える一覧と会話の画面の名前が変わる。その後に読んだ同じチャットの画面も、同じ行に入るChat の title を書き換える (titleReadFromScreen は変えない)
一覧の行を押す会話の画面が開く。読み取った時点ごとに 1 ページで、画面の画像と翻訳と返信案とメモが出る。横に送ると前の時点に移るその chatID の ReadingMoment を capturedAt の順に読み、screenImage の画像を出す
ページで「この時点の動画を見る」を押す取り込みの動画が、その時点の位置から再生されるrecordingPosition の CaptureRecording の動画を読む。その CaptureRecording か動画のファイルが無い時 (14 日で先に消えた・再生できずに消した) は、この操作をページに出さない。画像・翻訳・返信案・メモは今までどおり出る
ページにメモを書くメモがその時点に残るReadingMoment の memo を書き換える
一覧で検索する発言・翻訳・メモ・チャットの名前に文字を含む読み取った時点が出るReadingMoment と Chat を読む (検索のための型は足さない)
(操作なし) 読んでから 14 日が過ぎるその読み取った時点とメモが消える。取り込みを始めてから 14 日が過ぎた動画も消える。読み取った時点が 1 つも無くなったチャットは一覧から消える本体アプリを開いた時と取り込みを始めた時に、14 日を過ぎた ReadingMoment・画像・CaptureRecording・動画と、読み取った時点の無い Chat を消す。写真ライブラリの元のスクリーンショットは消さない。本体アプリを開かない間は、14 日を過ぎても端末に残る (プライバシーポリシーにはこの形で書く)
設定で「読み取った内容をすべて消す」を押すすべての読み取った時点・動画・チャット・セクションと、キーボードに渡す読み取り結果が消える上の 4 つのディレクトリの中身と LatestReading を消す。写真ライブラリの元のスクリーンショットは消さない。取り込みの途中なら、取り込みを止めてから消す。消す操作より前に始まっていた読み取り (画面の読み取り・スクリーンショットからの読み取り) が後から終わっても、その結果は書かない (消したものが戻らない)

agent が決めたこと (違っていれば直す)

  • 「会話が大きく変わった所」: 前のページを作った時から、読めた発言のうち新しいものが半分を超えた時に、次のページを作る。実機で調整する
  • メモを付けた時点も 14 日で消える。残したい時点を 14 日より長く残す仕組み (お気に入り) は入れていない
  • チャットの名前を書き換えた後も、新しく読んだ画面は、画面から読んだままの名前 (titleReadFromScreen) で同じチャットかを比べる。2 つのチャットを 1 つにまとめる操作は入れていない
  • 発言した人の名前は画面の文字から読むので、読めない画面では人物ごとに分かれない
  • 画面の上部の名前が同じ別のチャット (Slack の「general」と Discord の「general」) は、同じチャットとして 1 行に入る。前面のアプリが何かを iOS が教えてくれず、アプリの名前を画面から判定するのもやめたため、見分ける値が無い。読み取った時点を別のチャットへ移す操作は入れていない。困る場面が多ければ、その操作を足す (ReadingMoment の chatID を書き換えられるようにするだけで、型は変えずに足せる)

確かめていないこと (実機で測る)

  • 本体アプリが背面にいる間も、取り込みの動画を書き出せるか。iOS 27 の SDK に書き出す API があることだけ確かめた
  • 取り込みがエラーや本体アプリの終了で途中で終わった時、動画のファイルが再生できるか
  • 動画と画像の 14 日分の大きさと、電池への影響。大きすぎる時は、動画だけ期間を短くする案を出す
  • 写真ライブラリの元の画像を、後から読み直せるか (スクリーンショットからの読み取りは、今も写真ライブラリの読み書きの許可を求めている)
  • 動画は、チャット以外の画面 (ホーム画面・ほかのアプリ・通知) も取り込みの間はすべて残る
